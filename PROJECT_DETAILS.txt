PROJECT DETAILS
===============

Project name
------------
Ravi Vishnoi - Web Developer and Cybersecurity Portfolio

Project type
------------
Single-page responsive personal portfolio website.
The project is a static frontend made with HTML, CSS, and vanilla JavaScript.
There is no backend or build system. Open index.html in a browser to run it.

JavaScript behavior
-------------------
File: script.js

1. DOMContentLoaded initialization
All behavior is registered after the HTML document has loaded.

2. Mobile menu
A mobile menu button is created dynamically and inserted into .header-content.
Clicking it toggles the .show class on the main navigation.

3. Smooth navigation
Internal links beginning with # are intercepted. The page scrolls smoothly to the target,
leaving an 80px offset for the fixed header. The mobile menu closes after navigation.

4. About tabs
Clicking a .tab-btn removes active states from all tabs and activates the selected tab
content using its data-tab value.

5. Project filtering
Filter buttons use data-filter values. Cards are shown when their data-category matches
the selected filter, or when the All filter is selected. Hidden cards fade and move downward.

6. Contact form
Prevents the normal submit action, checks name/email/message, displays an alert, and resets
the form after the simulated success message.

7. Scroll reveal animations
Skill items, certification cards, project cards, and timeline items start hidden and move
into place when they enter the viewport. The check runs once on load and again on scroll.

8. Header scroll effect
After scrolling more than 100px, the header receives a translucent white background and a
slightly stronger shadow. At the top, the original card background and shadow are restored.

9. Skill bars
For each .skill-item, script.js creates .skill-bar and .skill-progress elements. The
progress width animates to the percentage stored in data-skill.

Responsive behavior
-------------------
- Up to 992px:
  - Hero columns stack vertically.
  - About content stacks vertically.
  - Contact content stacks vertically.
  - Education timeline moves to a left-side vertical line.

- Up to 768px:
  - Header content stacks vertically.
  - Navigation wraps and centers.
  - Hero heading becomes smaller.
  - Hero buttons stack vertically.
  - Experience statistics stack vertically.
  - Project grid becomes one column.

- Up to 576px:
  - Section padding reduces to 60px.
  - Section headings and hero heading become smaller.
  - Skill items use one column.

Current implementation notes
----------------------------
- This remains a static frontend. Contact form submissions are simulated and are not persisted.
- The Hero is an isolated React/TypeScript/Tailwind build in src/ and is mounted from hero-dist/;
  the rest of the portfolio remains HTML/CSS/vanilla JavaScript.
- The Hero component is src/components/ui/cyber-network-hero.tsx: a Canvas2D node network with
  a looping secure-shell terminal, reduced-motion support, and the existing portfolio CTA anchors.
- The Network Vulnerability Scanner report and GitHub buttons still use placeholder # links.
- The project uses npm only to build the isolated Hero and its shadcn-style Button primitive.
- index.html references icon images directly and does not include an external icon library.
- The generated mobile menu button uses a Font Awesome class name, but no Font Awesome stylesheet
  is linked in index.html; the button may therefore not display the expected bars icon.
- The CSS contains some legacy selectors for <i> icons while the HTML primarily uses <img> icons.

How to run
----------
1. Open the project folder in VS Code.
2. Run npm run build:hero after changing files under src/.
3. Open index.html directly in a browser, or use a static live-server extension.
4. Scroll through the page to see hero scrubbing, reveal animations, and the header scroll effect.
5. Test the About tabs, project filters, internal navigation, contact form, tilt cards, and desktop cursor.
